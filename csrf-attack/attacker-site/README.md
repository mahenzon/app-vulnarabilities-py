# Attacker Site - CSRF Attack Demo

Этот каталог содержит вредоносный сайт для демонстрации CSRF атаки.

## Как запустить

В директории выше есть `docker-compose` конфиг для локального запуска nginx. Или запустите отдельно по инструкции ниже.

В **отдельном терминале**:

```bash
# зайдите в текущую директорию
cd attacker-site
python3 -m http.server 8080
```

Сервер запустится на http://localhost:8080

Нажмите `Ctrl+C`, чтобы остановить.
